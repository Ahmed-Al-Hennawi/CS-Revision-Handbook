# Computer Science & Software Engineering — The Graduate Revision Handbook

An offline-first, comprehensive revision handbook and interactive assessment tool designed for computer science graduates refreshing their fundamentals for technical interviews and engineering roles.

## Features
- **30+ Core Chapters:** Covers computer science mental models, data structures, algorithms, databases, web development, systems, security, delivery, and interview skills.
- **Interactive Self-Assessment:** Includes a 40-question multiple-choice quiz with persistent local storage tracking.
- **Dark/Light Mode:** Seamless theme switching built right into the interface.
- **Fully Offline:** No external accounts or libraries required.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser.
